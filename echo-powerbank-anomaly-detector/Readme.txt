# Echo Powerbank — Anomaly Detector (STALKER)

A 3D‑printed STALKER‑style anomaly detector with integrated powerbank functionality.  
This project combines Arduino Nano, RCWL‑0516 motion sensing, RGB LED indication, voltage monitoring, and a buzzer alert system — all inside a custom resin‑printed enclosure.

---

## Features
- Motion detection using **RCWL‑0516**
- Battery level indication via **RGB LED**
- Audible alert using **buzzer**
- Two operating modes:
  - **Anomaly detection**
  - **Battery level monitor**
- Powerbank functionality (IP5328P board)
- Designed for **5×18650** cells (or 21700 with body modification)
- Fully 3D‑printed enclosure (Tough Resin Ultra)
